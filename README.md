# CSS Flexbox – Flexible Layouts

Dieses Repository enthält Unterrichtsmaterialien, Codebeispiele und Übungen zum **CSS Flexible Box Layout (Flexbox)**.

Die Beispiele vermitteln schrittweise, wie sich Elemente flexibel anordnen, ausrichten und verteilen lassen.

## Kursinhalte

- Grundlagen des Flexbox-Layouts
- Flex-Container und Flex-Items
- Hauptachse und Querachse
- Richtung und Reihenfolge mit `flex-direction` und `order`
- Zeilenumbruch mit `flex-wrap` und `flex-flow`
- Ausrichtung mit `justify-content`, `align-items`, `align-content` und `align-self`
- Abstände zwischen Elementen mit `gap`
- Flexible Größen mit `flex-grow`, `flex-shrink` und `flex-basis`
- Die Kurzschreibweise `flex`
- Praktische Umsetzung von Navigationsleisten, Formularen und responsiven Layoutbereichen

## Entwicklungsumgebung

Die Beispiele sind für die Arbeit mit **Visual Studio Code** vorgesehen.

Die HTML-Dateien können direkt im Browser geöffnet werden. Ein Webserver oder zusätzliche Build-Werkzeuge sind nicht erforderlich.

## Übungen

Die enthaltenen Beispiele und Übungen dienen dazu, das Verhalten der verschiedenen Flexbox-Eigenschaften praktisch nachzuvollziehen.

Als ergänzende Übung eignet sich das interaktive Lernspiel [Flexbox Froggy](https://flexboxfroggy.com/#de).
